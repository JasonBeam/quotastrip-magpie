# QuotaStrip v1.2.0

这一版把 QuotaStrip 从“单个 Codex 额度条”扩展成以 Codex + Magpie 为核心的本地用量面板。
Touch Bar 继续只保留额度模块和系统 Control Strip；更完整的统计放在菜单栏面板里。

## 更新内容

- Touch Bar 新增 Magpie Token Plan 模块：剩余百分比、今日 Token、当前模型、缓存命中率和 tok/s。
- Codex 同时显示 5 小时和 7 天剩余额度，优先使用 Magpie，失败后回退 app-server 和本地日志。
- 新增千问、Kimi Code 供应商卡和 Kimi 额度窗口。
- 新增完整历史热力图，最近一天的 Magpie 缓存重建不会清空已有历史。
- 热力图 Tooltip 跟随日期方块，显示日期、星期和当天 Token；左右边缘自动防裁切。
- 保持 Codex/ChatGPT 启停联动、20 秒刷新和菜单栏控制入口。

## 安装

1. 下载 `QuotaStrip.zip` 和 `SHA256SUMS.txt`。
2. 执行 `shasum -a 256 QuotaStrip.zip` 核对校验值。
3. 解压并把 `QuotaStrip.app` 放入 `/Applications`。
4. 首次启动使用 **Control-点击 → 打开** 接受未公证签名。
5. 若 Touch Bar 被其他应用占用，从菜单栏选择“重新显示 Touch Bar”。

不需要辅助功能权限，不修改 Codex 配置，也不会安装 Claude hooks 或 LaunchAgent。

## 数据与兼容性

- Magpie 为可选依赖；未运行时，Codex 继续使用 app-server 或 `~/.codex/sessions` 回退。
- 只有数据可靠时才显示百分比；未知值显示“暂无数据”。
- 支持 macOS 11 及以上、Intel 和 Apple Silicon；开机自启需 macOS 13 及以上。
- 发布构建已签名但未经过 Apple 公证。

## 验证范围

- 通用二进制构建、签名、面板/Magpie/组合测试和实际菜单栏面板交互已验证。
- 物理 Touch Bar 布局仍建议下载者按自己的设备和系统版本复核。
